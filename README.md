> AI-powered study assistant that transforms PDFs into personalized learning experiences.

ScholarAI is an AI-powered learning platform built with Google Gemini. Instead of simply summarizing documents, it helps students truly understand and remember what they study.

Students can upload lecture notes, textbooks, research papers, or any PDF, and ScholarAI automatically converts them into structured study materials.

---

## ✨ Features

- 📄 Upload PDF documents
- 🧠 AI-generated summaries
- 📝 Interactive quizzes
- 🎴 Smart flashcards
- 📚 Personalized study plans
- 💡 Simple explanations for difficult concepts
- ❓ Ask questions about uploaded documents
- 🤖 Gemini AI Tutor for follow-up questions
- 📈 Adaptive learning experience

---

## 🚀 How it works

1. Upload a PDF.
2. ScholarAI extracts and analyzes the content.
3. Google Gemini understands the document.
4. The system creates:
   - Summary
   - Flashcards
   - Quiz
   - Study Plan
   - Key Definitions
5. Students can continue learning by chatting with the built-in AI Tutor.

---

## 🎯 Why ScholarAI?

Most AI tools stop after generating a summary.

ScholarAI continues the learning process by helping students understand concepts, test themselves, review flashcards, and ask unlimited questions directly inside the platform.

Instead of searching through hundreds of pages, students receive an organized learning experience in seconds.

## 📦 Installation

Clone the repository.

```bash
git clone https://github.com/Shinigami-tech/ScholarAI.git
```

Install dependencies.

```bash
npm install
```

Run the development server.

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
